# Consilium 2.0.0-alpha.2

- Open tasks in retained tabs with a main document, details, folder link and AI chat.
- Hover briefly for basic task details and Complete / Mark incomplete buttons.
- Write in the embedded Wordcraft editor, save locally, and export DOCX.
- Use separate task documents or shared label documents and conversations.
- Link a local folder and open it in Explorer.
- Keep drafts intact when another tab changes the saved document.

This is an unsigned development alpha. Task/label chat is conversational and cannot modify tasks yet. Folder contents are not automatically read or shared. Advanced editor compatibility, accessibility, clean-machine installation and performance remain under review.
